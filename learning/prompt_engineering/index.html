Introduction

In this blog I am documenting my learning journey of prompt engineering. I use ChatGPT (GPT-5) for this task.

I initially prompted the chat to create a syllabus for me. I mentioned that I am a developer and comfortable with technical workflows as I prompted the chat to give me the syllabus. This syllabus is listed at the end of this blog (as a summary).

As I am learning, I am using

  • one chat thread as my classroom
  • a second chat as a sandbox to test out prompts
  • a repo as a storage of good prompts. (https://github.com/jac0bmath3w/prompt-engineering.git)

Phase 1 Lesson 1: Prompt Engineering vs Casual Use.

In casual prompting, I would just be typing what I want without any structure. For example: - Summarize “Finding Nemo” movie for me. - Explain the difference between AUC-ROC and AUC-PR.

On the other hand, engineered prompt adds - role - context - constraints - desired output format - focus etc.

An example of this would be: - You are a film critic. Summarize Finding Nemo in 3 sentences, focusing on the main plot. Highlight the emotional themes of family and perseverance. End with a one-line moral lesson.

This prompt includes role (film critic), constraints (3 sentences), focus (main plot, emotional themes), output structure (ending with one-line lesson).

Experiment 1

Casual Prompt

Prompt: Summarize "Finding Nemo" movie for me
Result:
Here’s a quick, spoiler-light summary of Finding Nemo:

Marlin, an anxious clownfish, loses his son Nemo when the curious kid is captured by a diver and placed in a dentist’s fish tank in Sydney. Determined to get him back, Marlin crosses the ocean, reluctantly teaming up with Dory, a cheerful blue tang with short-term memory loss. Along the way they survive sharks, jellyfish, and a surfer-dude sea turtle named Crush, learning courage and trust. Meanwhile, Nemo plots escape with the tank gang. Father and son’s parallel journeys push both to grow—Marlin learns to let go and believe in Nemo, and Nemo gains confidence and independence.

Themes: parental love, overprotection vs. resilience, friendship, and facing fears—with lots of humor and heart from Pixar’s vibrant undersea world.

Engineered Prompt

Prompt: You are a film critic. Summarize *Finding Nemo* in 3 sentences, focusing on the main plot. Highlight the emotional themes of family and perseverance. End with a one-line moral lesson.
Result:
Finding Nemo follows Marlin, a fearful clownfish father, as he crosses the ocean to rescue his captured son, Nemo, who’s stuck in a Sydney dentist’s fish tank. Along the way, Marlin partners with the forgetful yet steadfast Dory, surviving sharks, jellyfish, and the open sea while Nemo, encouraged by the tank gang, discovers his own courage and ingenuity. Their parallel struggles converge in a reunion that softens Marlin’s overprotectiveness and celebrates Nemo’s growing independence, underscoring how love steels perseverance.

Moral: Trust empowers growth—letting go is sometimes the bravest way to hold on.

Here, something I noticed: Prompt engineering doesn’t necessarily make a huge difference on simple, well-trained tasks like the example above. My teacher (ChatGPT) says prompt engineering really shines when you need consistency, control or specialized behavior. Here is another example to highlight this point.

Experiment 2

Casual Prompt

Prompt: 
Extract the important details from this customer complaint:

"Hi, my name is Sarah Johnson. I ordered a blender last week but it arrived broken. Please send a replacement quickly, I need it before Saturday."

Result:
Here are the key details pulled from the complaint:

Customer name: Sarah Johnson

Product: Blender

Issue: Arrived broken (damaged on arrival)

Requested action: Send a replacement

Urgency: “Quickly”; needs it before Saturday (exact date depends on when this was received; if today is Sep 24, 2025, Saturday is Sep 27, 2025)

Order timing: “Last week” (no exact date)

Missing info to resolve fast: order number, shipping address/confirmation, preferred contact method.

Engineered Prompt

Prompt:
You are a data extraction system. From the following text, extract the customer_name, product, issue, and urgency. Return the result in valid JSON with keys: customer_name, product, issue, urgency.

Text: "Hi, my name is Sarah Johnson. I ordered a blender last week but it arrived broken. Please send a replacement quickly, I need it before Saturday."

Result:
{
"customer_name": "Sarah Johnson",
"product": "blender",
"issue": "arrived broken",
"urgency": "replacement requested quickly; needed before Saturday"
}

While in a quick glance, it might appear that the casual prompt gave richer details and thus might be better the engineered prompt gives two critical advantages:

  • Reliability
    • JSON is machine parseable
    • This result can be fed directly into a pipeline, or API
    • the output will always have the same keys.
  • Control
    • You can expand the fields as needed (say add order number)
    • specify strict formats
    • force errors when data is missing.

Neither is better than the other, it depends on what purpose you use it for.

Experiment 3

Casual Prompt (Rich Extraction Casual Style)

Prompt:

Extract all useful details from this customer complaint, including inferred context (like missing info or urgency reasoning). Write in natural language for a human support agent.

Input:
"Hi, my name is Sarah Johnson. I ordered a blender last week but it arrived broken. Please send a replacement quickly, I need it before Saturday."

Result:
Here’s a concise, agent-ready brief:

Summary:
Sarah Johnson reports that the blender she ordered last week arrived broken. She’s asking for a replacement to be sent quickly and specifically needs it before Saturday.

Key details provided:

Customer name: Sarah Johnson

Product: Blender

Problem: Item arrived damaged (DOA)

Requested action: Replacement (not a refund)

Deadline/urgency: Needs delivery before Saturday → with today being Sep 24, 2025 (Wed), the deadline is Sep 27, 2025 (Sat).

Order timing: “Last week” (exact date not given)

Inferred context & reasoning:

This is likely a standard DOA replacement; speed of fulfillment is critical due to the stated deadline.

Shipping method may need to be expedited to arrive by Sep 27 depending on warehouse location and cutoff times.

Missing info to resolve quickly:

Order number and email/phone on the order

Shipping address (confirm if same as original)

Preferred replacement option (same model) and consent to reship

Photo of damage (if policy requires)

Any constraints for delivery (e.g., no-signature, leave at door)

Recommended next steps for the agent:

Locate the order using name + email/phone; request the order number if needed.

Offer an immediate replacement with expedited shipping to meet the Sep 27 deadline.

If policy requires evidence, ask for a quick photo of the damage but don’t let it delay dispatch (allow post-shipment submission if policy permits).

Provide an ETA and tracking once processed; set expectations on cutoff times.

One-paragraph reply draft:
“Hi Sarah, I’m so sorry your blender arrived damaged—that’s not the experience we want for you. I can send a replacement right away and make sure it arrives before Saturday (Sep 27). Could you please share your order number and confirm the shipping address? If you have a quick photo of the damage, that helps us improve our packaging, but we won’t let that delay your replacement. Once I have those details, I’ll process an expedited reship and send your tracking info immediately.”

Experiment 4

Structured Extraction (Engineered Style)

Prompt:
Now, from the same text, extract only the structured data fields: customer_name, product, issue, urgency. Return in valid JSON only.
Result:

{
"customer_name": "Sarah Johnson",
"product": "blender",
"issue": "arrived broken",
"urgency": "replacement requested quickly; needed before Saturday"
}

Here we see the rich extraction has the following features (or lack of):

  • Agent ready brief with context and missing info, and suggested reply draft
  • Human friendly
  • Not consistent

And the structured extraction is

  • machine usable
  • consistent
  • but loses any nuances.

Phase 1 – Lesson 2: Prompt Templates & Structures

The goal of this lesson is to learn how to design reusable prompt templates instead of one-off prompts. A prompt template is like a function definition. It is a prompt with placeholders that you can fill in later. Example: Instead of writing “Summarize the movie ‘Finding Nemo’ in 3 sentences”, I can use a template of the format “Summarize the movie {movie_name} in {n_sent} sentence”. Now I can use this template for any movies and get any value for n_sent in my output.

A good template usually includes

  1. Role/Instructrucion
  2. Task/Goal
  3. Constraints
  4. Placeholder

Experiment 1:

Casual one-off prompt

Prompt: Summarize this meeting transcript
Alice: We need to finalize the Q4 marketing budget.
Bob: Agreed. Let’s set it at $50,000 and allocate 60% to digital ads.
Carol: Deadline for campaign launch is November 1.
Dave: Action items — Bob drafts budget proposal, Carol coordinates with design.

Result:

Q4 Marketing Meeting – Summary

Decision: Set the Q4 marketing budget at $50,000 with 60% allocated to digital ads.

Deadline: Campaign launch on November 1.

Action Items:

Bob: Draft the budget proposal.

Carol: Coordinate with the design team.

Engineered template

Prompt:
You are an executive assistant. Summarize the following meeting transcript in {n_bullet_points} bullet points. Focus on action items, decisions made, and deadlines. Format as Markdown.
Transcript: {meeting_transcript}

Where

- n_bullet_points = 5
- meeting_transcrpt =  "Alice: We need to finalize the Q4 marketing budget.
Bob: Agreed. Let’s set it at $50,000 and allocate 60% to digital ads.
Carol: Deadline for campaign launch is November 1.
Dave: Action items — Bob drafts budget proposal, Carol coordinates with design."

Result:

- Decision: Set the Q4 marketing budget at $50,000.

- Allocation: 60% of the budget goes to digital ads.

- Deadline: Campaign launch on November 1.

- Action Item (Bob): Draft the budget proposal.

- Action Item (Carol): Coordinate with the design team for campaign assets.
